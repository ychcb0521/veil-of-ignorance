# 支撑质量：二次急跌未收复前高（538）

用户指出 SAPIEN 图中的加仓前已经出现两次明显回落、未收复前高，要求规避并明确确认上线。新增独立加仓否决 `addition-double-drop-v1`；DBL-5、SBS-5M 和防守线原生公式、输出与旧版说明均不变。

## 使用

持仓监测 → 条件设置 → 加仓 → 选择对应次数 → 否决 → 勾选「二次急跌未收复」。用户确认的填写默认值为回落 ≥2.5ATR **且** ≥4%；可改数字、且/或，或单独留空一项。至少保留一个大于零的门槛。新选项默认未勾选，各次加仓单独设置，已有方案不自动启用。

## 计算

- 使用首次买入后、截至当前加仓判断时点已收盘的连续 5 分钟 K 线。沿用盘面 ATR(14) 的现有 EMA 序列；不修改 ATR 公式。
- 价格从观察前高回落至所设门槛，记第一次急跌。连续下跌无论多少根都只记一次。
- 第一次触发时固定前高与当时 ATR，避免 ATR 漂移凭空改变急跌区。只有收盘反弹离开急跌区，随后再次下降并达到门槛，才记第二次。
- 第二次后，加仓一票否决保持有效；一般反弹、再次出现箱体或新防守线均不解除。须完整 5 分钟收盘 ≥ 首次急跌前高才恢复，单根上影冲高不解除。恢复后重新计数。
- 该规则不模拟退出，不更改原加仓数量、止损 K/F、实际成交阶段或 BTC 指标。
- 读取不到必要 ATR、行情无效或观察区间有缺口时停止并报错，不把未知状态当作安全支撑。

## 版本与兼容

仅勾选后新增运行身份和冻结参数指纹，原六类否决及未勾选方案的身份不变。每个加仓判断均从同一观察起点恢复状态，暂停续算结果一致。冻结清单显示新引擎版本与参数，改动参数须保存新清单。旧版本不认识的新规则不能冒充原版运行。

动态筛选 v4 的存档保持原样，本次没有把新规则塞进旧轮次；三阶动态准入仍是另一个尚未实现的规划。共享编辑器在买前模式隐藏这条新版加仓专用选项，运行验证也拒绝将其放入 v4。
