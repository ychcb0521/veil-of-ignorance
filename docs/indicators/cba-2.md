# CBA-2｜成交支持下的价格重心迁移指标

来源：用户 2026-10-18 提供的三张推导截图。独立于原有 CBA，Deep dig 的第六个内置特征值，盘面菜单名称 CBA-2。只使用已结束的 5 分钟 K 线。

主公式：

`CBA-2_t = 100 tanh(Σ w_i,t F*_i G*_i R*_i)`

- `w_i,t = 2^(-ΔT_i,t/h) / Σ 2^(-ΔT_j,t/h)`，截至当前的48小时窗口，时间单位小时，权重合计1。
- `F*_i = ln(1 + V_i / Vbar_(i-1))`。
- `G*_i = 1 + α |D_i|/V_i · 1{D_i r_i > 0}`。
- `R*_i = r_i / s_(i-1)`。
- `V_i = B_i + S_i`，`D_i = B_i - S_i`，均为成交金额，D不是市场净资金流入。
- `E_i = 成交金额 / 成交数量`（VWAP），`r_i = ln(E_i/E_(i-1))`。
- `s_(i-1) = sqrt(EWMA_(i-1)(r²) + ε²)`，严格只用上一根及以前的数据。

正值表示加权上行变化占优，负值表示加权下行变化占优；压缩范围 −100 至100，不是胜率。

独立失效条件：

`Ppeak_t = max(C_(t-m), …, C_t)`（含当前共m+1个收盘价）。

`DD_t = ln(Ppeak_t/C_t)/s_(t-1)`，`DD_t > dmax` 时，暂停认定为有效做多候选。

失效不清零主值，不替代交易止损。未触发失效不等于满足买入条件。盘面红点表示失效；Deep dig保留DD和invalid两个可选中间变量。

## 经用户确认的研究默认值

- 时间权重半衰期h：6小时；盘面参数与Deep dig半衰期选择可改。
- 历史基线：截至上一根、过去24小时成交额均值；r² EWMA半衰期亦为24小时。Deep dig由avgh控制，两者可在公式中拆开修改。
- α=1、ε=0.000001、m=12根、dmax=3；可在Deep dig公式中修改。
- EWMA从首个有效r²起算；常态基线需完整就绪，每个有效主值需完整48小时贡献。关键数据缺失、断线或无成交时留空，不补零。
- Deep dig额外拉取基线历史（原值默认共73小时；叠加24小时均线时按公式自动延长至约96小时以上），不把基线预热数据算入48小时主窗口。
- 其他盘面周期留空；Deep dig内置CBA-2固定5分钟。参数与阈值尚需回测，读数不能解释为未来上涨概率。

实现：`src/lib/cba2.ts`，公式与盘面共用；通用完整窗口和滚动最高值函数在公式引擎中。测试包含独立逐项数学参考、正负对称性、时序边界、缺失、独立失效与两端一致性。

时间序列完整性：曲线显示区间以外还会额外获取足够的预热历史，完整请求按交易所上限分页，不截掉进场前的历史。旧版曲线缓存会提示重新运行描述统计；只有交易所确实没有历史或关键数据缺失时才留空，不补零、不插值。
