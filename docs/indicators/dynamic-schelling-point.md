# 动态谢林点指标（Dynamic Schelling Point, DSP）

> 规格：2026-10-15 用户给定（目标、公式、默认参数、图形展示）。本文记录实现口径、规格里没写死而由实现取定的地方，以及上线前用模拟行情看到的性质。
> 代码：`src/lib/dynamicSchellingPoint.ts`（纯计算）；`src/lib/customIndicators.ts`（klinecharts 指标 `DSP_CUSTOM` / `DSP_V_CUSTOM` / `DSP_A_CUSTOM`）；入口：主图右上角「指标」→ 量能 →「动态谢林点 DSP（含 V / A 副图）」。

## 1. 公式（与规格逐条对应）

| 量 | 定义 |
|---|---|
| Bₜ / Sₜ | 主动买入 / 卖出成交金额（USDT）。Bₜ = 币安 K 线第 11 列 taker buy quote volume，Sₜ = 第 8 列成交额 − Bₜ |
| Nₜ | \|Bₜ − Sₜ\| |
| Fₜ | ln(1 + Nₜ ÷ (EMA(Bₜ + Sₜ) + ε))，ε = 1e-9 |
| Aₜ | (Bₜ − Sₜ) ÷ (Bₜ + Sₜ + ε)，−1 ~ 1 |
| Gₜ | 1 + α·max(Aₜ, 0)，α = 1 |
| Rₜ | ln(Cₜ ÷ Cₜ₋₁)，首根 0 |
| Uₜ | Fₜ × Gₜ × Rₜ |
| Vₜ | ρ·Vₜ₋₁ + (1 − ρ)·Uₜ，V₋₁ = 0，ρ = 2^(−周期 ÷ h)，h = 6 小时（5 分钟线 ρ = 2^(−5/360)） |
| DSPₜ | DSPₜ₋₁ × e^(κ·Vₜ)，DSP₀ = C₀，κ = 1 |

## 1b. 谢林点迁移速度 V：定义与计算（2026-10-16 补写）

**定义**：共识价每根 K 线往上（+）或往下（−）移动多少。它是近 h 小时里单根推动力 Uₜ = Fₜ × Gₜ × Rₜ 的指数加权平均，也是 DSP 每根的对数变化（κ = 1）。

展开：Vₜ = (1 − ρ)·Σₖ ρᵏ·Uₜ₋ₖ，权重之和为 1。5 分钟线、h = 6 小时：ρ = 2^(−5/360) ≈ 0.9904，每根新推动占约 0.96%，6 小时前的推动权重减半。

**例**：B = 60 万、S = 40 万、EMA(B + S) = 80 万、收盘 1.000 → 1.010、上一根 V = 2 基点：
N = 20 万，F = ln(1.25) = 0.223，A = 0.2，G = 1.2，R = ln(1.01) = 0.995%，U = 26.6 基点，V = 0.9904 × 2 + 0.0096 × 26.6 = **2.24 基点 / 根**。

**单位**：副图按 基点 / 根（× 10⁴）显示；1 基点 / 根 ≈ 每小时 0.12%。

**界面上的说明**：指标面板里两项「动态谢林点」的名称下面写着一句定义，悬停时（也可以停在图右上角的「DSP」小标签上）给出完整计算步骤（`DSP_V_DEFINITION` / `DSP_V_STEPS`）；使用说明里有同名一节。

## 2. 规格没写死、实现取定的地方

1. **EMA(Bₜ + Sₜ)**：与 Vₜ 同一个 ρ（同一个半衰期），首根取当根成交额，含当根。
2. **非 5 分钟周期**：ρ 按实际周期换算，保持「半衰期 = h 小时」。
3. **缺成交额 / 主动买入额的 K 线**：不用币数代替；这一根 Fₜ = 0（不推动共识），Aₜ 留空，Vₜ 照常衰减。
4. **成形中的 K 线**（回放时最后一根）：成交额、主动买入额与成交量一样按进度缩放，主动买入占比不变。
5. **显示单位**：V 显示为基点 / 根（× 10⁴），只换单位；A 原值。
6. **参数入口**：指标面板里的数字就是 h（小时）；α、κ 固定为默认值。
7. **着色**：DSP 线和 V 线每一段按段终点那根 K 线的 V 着色（V > 0 绿、< 0 红），最新一段反映最新一根，不晚一根。
   V 副图的 0 轴（上移 / 下移的分水岭）是橘黄色虚线（2026-10-16 用户要求，先实线后改虚线）；A 副图的 0 轴是灰色细虚线。
8. **只要副图**（2026-10-16 用户要求）：菜单项「动态谢林点 V / A（只要副图）」不画主图 DSP 线，只开 V、A 两个副图；与「DSP（含 V / A 副图）」二选一。
9. **回放逐根推送也带金额**（2026-10-16 修复）：交易主图回放时由 `Index.tsx` 逐根 `updateData`，此前只带 OHLCV，最新几根算不出 A、V 也只会衰减，要等整批刷新才补上；现在四条推送路径都经 `chartAmountFields` 带上成交额与主动买入额。

**V 本身的平滑**：V 是半衰期 h 的指数平滑（规格如此），一根 K 线的推动只占约 1 − ρ（h = 6 小时、5 分钟线时约 1%），所以 V 变号、DSP 线变色需要一段持续的反向推动；要更快就把 h 调小（例如 1 或 2 小时）。A 是单根读数，没有平滑，当根即现。

## 3. 上线前看到的性质（模拟行情，需在真实盘面上确认）

容器的网络策略不放行币安，用「收益与主动失衡正相关」的模拟 5 分钟行情（7 天 2016 根）试算：

| 行情 | 价格 | DSP | ln(DSP) ÷ ln(价格) | F 中位数 | \|V\| 中位数（基点/根） |
|---|---|---|---|---|---|
| 平稳 | ×1.105 | ×1.062 | 0.61 | 0.082 | 0.35 |
| 上涨趋势 | ×2.474 | ×1.178 | 0.18 | 0.082 | 0.82 |
| 高波动 | ×6.541 | ×1.501 | 0.22 | 0.082 | 2.05 |

- **DSP 只跟上价格对数变动的一小部分。** 长期看 ΣVₜ ≈ ΣUₜ = Σ Fₜ·Gₜ·Rₜ，而 Fₜ 一般只有 0.05～0.3，所以 κ = 1 时趋势行情里 DSP 会离 K 线越来越远。
- **起点依赖。** DSP₀ = 图上最早一根的收盘价：图表往左加载更多历史，整条线会平移。
- **主图纵轴会把 DSP 算进去**（klinecharts 的行为）：DSP 离价格很远时，K 线会被压扁。

这三点都来自公式本身，按规格原样实现，留给用户决定是否调整（可选：调大 κ、给 DSP 加向价格回归的项、或把 DSP 改成相对指数画在副图）。

## 4. 自检（单元测试 `src/lib/__tests__/dynamicSchellingPoint.test.ts`）

- ρ = 2^(−5/360)；三根 K 线手算 N、EMA、F、A、G、R、U、V、DSP 全部吻合。
- α = 0 时买方不加权；κ 线性放大 DSP 的对数移动；半衰期越短 V 越快。
- 大资金 + 买方优势 + 上涨 → 强正值；资金很小 → 影响弱；大资金 + 下跌 → 强负值。
- 缺成交额：A 留空、F = 0、V 只衰减。
- 币安 K 线数组第 8 / 11 列 → 成交额 / 主动买入额；缺列不带。
