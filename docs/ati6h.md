# ATI-6H｜加仓支持证据指数

ATI-6H 是只研究做多的市场证据特征。自制区指标列表和 Deep Dig 目录新增独立的 `ati6h`（图表代码 `ATI6H`），不覆盖旧 ATI 或其他特征；不增加加仓门槛、次数、数量、仓位、杠杆或订单逻辑。

## 已核对的接口

- `src/lib/mbi2.ts` 的 `mbi2StateLabel(2)` 明确为买方确认。ATI 的 A 直接读取现有 MBI2 定义输出的 `MBI2_state`；有效且不等于 +2 时为 0，缺失时为 null。
- MBI2 的递推 S 是同周期单根对数收益平方的指数均值，α=1/n。新加只读输出 `sigmaBefore[t]=sqrt(S[t−1])`，没有年化、没有乘 κ，也不是 z 或 MBI2 分数。它是无减均值的收益 RMS 波动尺度，沿用现有 MBI2 的定义。只有原 5n 预热完成后才输出；原 z、MBI2、均值、状态机和递推更新不变。
- `ResearchBar` 已有 OHLC、quoteVolume 和 takerBuyQuoteVolume。默认固定 taker 模式，主动卖出金额=总计价成交额−主动买入金额。ATI 专用严格解析保留越界金额，由 ATI 报错；其他特征的解析和数值不变。
- 交易所 `PRICE_FILTER.tickSize` 通过 ATI 专用公开 exchangeInfo 适配读取，不用显示小数位或基础币成交量推算。缺失精度时完整指数为空。
- ATI 的新增局部证据为最近 6h，默认 72 根已收盘 5m；允许之前紧邻的收盘价只作收益基点。外部 MBI2 状态和 RMS 保留自身递推历史及预热。额外加载这些预热数据，不代表把它们纳入 ATI 的收益、成交、插针或结构证据。
- 不继承默认 48h 汇总，不自动生成 avg 或 avg₂，添加原生指标只创建原值副图。可像 CDA 一样搜索、勾选、移除和保存选择；副图为 0–1，悬停读取六分量、最弱项和固定结构价位。Deep Dig 的原有样本分组、事后收益标签和控制波动率继续作为评估用途，不进入 ATI 计算。

## 参数与模式

默认 WINDOW_HOURS=6，HALF_LIFE_HOURS=1，PIVOT_CONFIRM_MINUTES=10，ADJUST_MIN_MINUTES=15，ADJUST_DEPTH_SIGMA=1，BAND_SIGMA=0.5，INITIAL_SUPPORT_CAP=0.5，RETEST_MAX_MINUTES=30，WICK_OK=1.5，WICK_BAD=3，RESISTANCE_ROOM_SIGMA=3。

A/B/C/D/E/F 权重为 0.15/0.35/0.20/0.10/0.10/0.10。默认参数是工程初值，没有按样本内收益寻优。其他周期的分形左右确认与调整/回踩时间按实际时间向上换算。Deep Dig 半衰期设置用于证据衰减；完整参数也可在定义的 `ATI6H_parameters` 中配置，成交模式为 `ATI6H_volume_mode`。变更模式或参数后定义键改变，旧结果不能冒充新结果；每份运行结果保存参数、模式和外部 MBI2 定义快照。

固定模式 `bar_direction_proxy` 使用完整计价成交额和价格方向，平盘金额各分一半，界面明确显示“成交方向代理”。不会逐根静默切换模式。

## 输出

所有新增结果字段使用 `ATI6H_` 前缀，主综合分按要求保留 `ATI6H`。

- 主字段：`ATI6H`、`ATI6H_sA`…`ATI6H_sF`、`ATI6H_min`、`ATI6H_shortboard`、`ATI6H_data_status`、`ATI6H_reason_codes`、`ATI6H_volume_mode`、`ATI6H_version`。
- 结构：`ATI6H_structure_id`、`ATI6H_structure_status`、高低锚点及确认时刻，`ATI6H_support_price`、支撑上下沿与失效价，`ATI6H_pre_adjustment_high`、`ATI6H_breakout_price`、最近阻力价及其突破价/类型/锚点。
- 事件：支撑确认、触碰、回踩确认/超时、破位、过期、数据中断、结构替代、首次观测突破与当根穿越。都是市场事件，不是实际成交或加仓 Leg。
- 调试：`ATI6H_s_CP`、`ATI6H_s_CV`、`ATI6H_U_P`、`ATI6H_D_P`、`ATI6H_U_V`、`ATI6H_D_V`、`ATI6H_downside_rms`，插针原始与时间加权极值/时刻，初始/最佳回踩证据、位置因子、回踩时刻与状态，冻结的 `ATI6H_v_0`、`ATI6H_delta_S`、`ATI6H_delta_H`，完整参数与数据模式。

分量缺失时已知项继续展示，完整综合分和完整短板字段为空。有效零分先于对数计算，完整综合分为 0。非零时使用指定加权几何平均，不再乘最小值。指数处于各分量的最小值与最大值之间；具有零值否决和短板惩罚，非零短板仍可被其他高分部分补偿。分数不是概率、胜率或独立事件概率乘积。

## 保存、评估、导出与图表

主盘面指标与 CDA 使用同一原生注册、菜单、后台计算、历史预热和已收盘遮罩链路；不同周期按真实分钟数换算，价格精度通过公开元数据加载后自动重算。

沿用现有公式变量→Deep Dig 描述统计→推断统计→本机结果/IndexedDB 曲线的路径。ATI 数值与曲线使用双精度；显示层才舍入。

每条样本保存当前解释行和失败/过期/替代结构归档；IndexedDB 中另存当前样本 6h 的逐根解释及价格。CSV 包含数值变量、完整解释 JSON、归档及外部依赖快照。面板可导出逐根结构与参数 JSON。

描述统计的时间序列区域新增 ATI 证据面板，可选样本和收盘时点，显示综合分、六个分量、最弱项、固定支撑和失效价、固定突破线、最近阻力以及市场事件。不同结构之间断开绘线，不把旧结构线移动到新位置。没有结构时明确显示原因。

## 数据限制

- 需要网站可获取币安公开行情及 exchangeInfo。精度或必需行情缺失时，不能计算完整指数。
- 交易所公开接口返回当前 tick_size，并不提供完整历史精度变更档案。历史评估保存实际使用的 tick_size；不能保证该精度就是历史当时的交易规则。不能以显示精度替代。
- MBI2 的 σ 在现有代码中是收益 RMS，而不是减去均值后的样本标准差；本版本明确沿用这个原始外部波动尺度。外部 MBI2 自身的历史依赖仍在。
- 六小时规则内未检测到阻力，只说明本规则的可见候选为空；不代表市场上方绝对无阻力。D 较高表示时间衰减后的近期插针惩罚较低，不代表六小时内从未有严重插针。
- 页面自动捕捞只能在网站进程可运行时执行。休眠、断网后按上次扫描时间补一轮；关闭浏览器期间不能在本机执行扫描。
