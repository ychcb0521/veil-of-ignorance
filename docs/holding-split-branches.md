# 将结构 / 进攻组合拆成独立方案

在「持仓监测 → 条件设置」的组合方案上点击「拆成结构型 / 进攻型」，再保存方案。
原组合保留，新增两份独立编号的方案；拆分不会开始监测，也不会改写历史战役。
两份新方案没有条件分流器，分别从各自第一轮开始执行。

复制来源是该组合已经保存的完整分支，不是内置模板或当前账号公式重建的默认方案。
卖出算法、公式全文、镜像、各轮加仓条件和定量、K 止损执行版本、硬性终止、分段规则等原样保留。
「进攻型」名称不代表每一轮都使用指标 S/T/K：原分支后续轮次若配置了箱体规则，拆分后仍保留箱体规则。
未保存的编辑须先保存；冻结版本不匹配时拒绝拆分，不能借拆分升级旧算法。

原有历史绑定买入过滤与共同初始化也会沿用。拆分后可分别编辑、保存和运行，新编号与原组合的结果独立。
没有修改计算公式、分流引擎、任何内置模板或账号原有方案。

验证覆盖：完整分支字段对比、保存往返、对象独立、冻结版本保护、界面拆分及原组合保留、未保存编辑阻止拆分。
