## 确定性验证

18 根规格样例严格得到：1–7 空、8–13 为100、14–17 为102、18 空。第8根 BASELINE [100,104]；第14根 UP_STEP [102,106]；第16根触底不破坏；第18根虽收盘103，最低101仍破坏102，不回退100。

边界测试涵盖种子低点排除、最早p+4、相等上/下轨等待、并行同顶候选、1tick浅平台、重叠上移/内部抬高/同底新箱、统一候选选择、冻结坐标、严格影线破坏和双破、到期优先级及年轻候选保留、同根到期+新基线、数据缺口/无效/重复/冲突/乱序、JSON恢复和未来追加不改过去。

## 跨模块证据

- 实际 `collectDeepDigRun` 通过模拟供应商接口读取原始5m与真实接口形状的tick元数据，经过样本范围、统一计算、表格、序列、CSV及JSON。缺失8根、有效10根、破坏事件1次，空价格不吞掉事件。
- 信号锚点在第8根确认前1毫秒时读不到未来确认；确认收盘时才得到100。查询落入未观察到的5m缺口时不沿用旧值，粗采样网格亦如此。
- 原始价格限制单品种，三个派生量分别带bp/bp/分钟单位。捕捞使用布尔破坏字段仍可筛中下轨为空的第18根；重建保留配置与初始化时刻。
- 原生 KlineCharts 渲染器绘制位置为源K线收盘位置（开盘索引+1），十字线向后读取；null和episode断线。预热前缀、可视范围变化不移动初始化起点，已收盘修订提升数据版本。
- Worker 用独立原始十进制旁路包，测试 `123456789012345678.02` 到 `.03` 的一tick平台，防止Float64行情包先把边界取整。
- 检查点验证完整候选/主线/上下文恢复、源/品种/市场/tick/版本/起点隔离和未写盘告警。磁盘失败降级测试不冒充持久化成功。
- 使用实际 `Dbl5EvidenceView`、`CandlestickChart` 和指标菜单进行浏览器组件验收；详细证据默认折叠。18根本机预览保存在忽略目录 `generated/dbl5-validation/preview.html`。

这只是公开历史数据的结构联调，不是收益、支撑成功率或参数拟合；长期在线运行、多市场提供方和实盘效果未据此验证。

## 可复现命令与限制

最终相关回归为18个测试文件、145项全部通过（含原有SBS/PRS/ATI、Worker、行情加载和通用Deep Dig测试）；TypeScript `tsc --noEmit -p tsconfig.app.json`通过，`npm run build`通过，`git diff --check`通过。构建保留原有大chunk与Browserslist数据年龄提示，未升级依赖。本地原始日志在忽略目录 `generated/migration-audit/dbl-*.log`。

`node scripts/verify_dbl5m.mjs` 可独立重放规格样例；加 `--history <原始klines.json> --tick <真实tick> --symbol <标的>` 可重放供应商公开数据。脚本不读取凭据、不发网络请求、不写数据库。

当前实现不新增服务端特征API、数据库迁移、流服务或自动交易。其他周期盘面不变换成伪5m；没有可信tick的来源返回数据不可验证。不同初始化起点可能产生不同历史状态；复现时必须统一起点或完整检查点，不能以最后72根替代。
