# 4.8 Deep Dig

Deep Dig 用于研究：在同一套样本、同一个取样时点下，某个特征值与交易结果、后续行情有什么关系。入口是“复盘中心 → Deep dig”。先选特征值，再看定义、公式和参数，之后分别运行描述统计、推断统计、规律提取。

先抓住三个重点：**CDA 看卖方留下的价格优势，状态 S 看多空综合状态，DBL-5 看已确认的价格结构，其中防守线负责区分上涨与震荡下的结构保护参考**。三者回答的问题不同，不能互相替代，也不会仅因打开研究页就变成买卖指令。

本章介绍当前内置原版的口径。账号中修改过的定义、独立副本、已保存方案和历史模板，以各自保存的原文、参数、版本和生效范围为准；阅读说明不会升级、重存或改写它们。

## 4.8.1 开始

**先定样本**。在特征值页面选择交易战役或信号库，再填写实验组与对照组标准。战役研究沿用原流水线的同币 48 小时聚簇；信号库按每条信号自己的时间取样，不因为同币在 48 小时内出现多次就合成一条。两种来源的样本数与含义不同。

**再定口径**。核对指标名称、原值或中间变量、K 线周期、半衰期、平均时长、显示倍率和取样时间。公式中的 `hl`、`avgh` 按小时计；`prev`、按根的求和或均值仍按所选周期换算。公式没用到某个参数时，修改那个参数不会凭空改变对应分量。

**分三步研究**。描述统计负责取行情、按公式计算、分组、展示分布和逐条数据；推断统计在已有描述数据上按命令运行检验；规律提取整理结果，并允许手动修改文字。三步各有入口，保存定义不等于已经重新运行。

**看清时间**。入场或信号时点的特征值，只能使用当时已经可用的数据。时间序列的竖线可以移到进场前后；移到进场后的结果用于事后分析，不能拿来证明进场时已经知道未来。原生 DBL-5、SBS-5M 结构只在完整 5 分钟收盘后确认。

**先核数据，再看差异**。查看各组有效样本数、缺失、冲突分组和极端值。样本同时满足两组条件，不应当作两份独立证据；缺行情与指标未达标也不同。暂时删除极端值会影响当前统计口径，长期删减与暂时删减要分清，并同时查看保留和删减后的结果。

**回到执行**。研究得到的候选门槛，需要放到独立样本或后续时段验证。在“渔”中使用时，还要核对同名指标的公式快照、序列、确认时点和版本。研究页的事后分组、统计显著或规律文字，不会自动成为入场或持仓条件。

## 4.8.2 CDA

**定义**。CDA 的名称是“买方阻力”。它衡量过去成交支持下形成的向下价格位移，到当前还保留了多少：卖方虽然主动成交，但价格很快收回，其保留优势会减弱；向下位移持续保留，买方面临的卖方阻力更强。它使用成交金额、主动买卖方向、价格位移、时间衰减和波动率缩放，默认保留窗口为 48 小时。

**读数**。当前内置原版最终输出在 −100～100 之间：越低、越负，表示卖方保留的向下优势越强；向零或正值回升，表示这部分优势减弱或被收复。它是状态评分，不是订单簿上的阻力价位，不是下跌速度，也不是下跌概率。

例如，同口径下的 −40 比 −5 更偏向“卖方优势仍在”。但 −40 不是“下跌概率 40%”；接近饱和区后，读数变化与底层位移也不是线性对应。比较不同币种时仍须匹配周期、窗口、公式和样本条件。

**公式**。下式是当前内置原版最终输出的等价简写，已包含卖方方向的统一；不要只取完整公式中的某一行中间值当成最终 CDA。

```text
B、S = 主动买入、主动卖出成交金额；Q = B + S
E = 当根成交均价；C = 收盘价
D = S − B；A = D / Q
V̄ = 截至上一根的 avgh 小时平均成交金额
F = ln[1 + (|D| + 0.5 × (Q − |D|)) / V̄]
G = 1 + max(A, 0)
P_t = max(E_t, C_t)
σ_t = 截至上一根的 avgh 小时成交均价对数收益率标准差

R_t = Σ w_i × F_i × G_i × ln(P_t / E_(i−1)) / (t−i+1)
w_i ∝ 2^(−距今小时 / hl)，在过去 48 小时窗口内归一化
最终 CDA_t = 100 × tanh(R_t / σ_t)
```

历史成交的支持和卖方权重在各自时点形成，再用**当前价格**重新衡量当时的位移还剩多少；`t−i+1` 是经过的 K 线根数。当前价格取成交均价与收盘价中的较高者，使向下成果的评估更保守。不是把过去每根的旧 CDA 简单平均，也不是用未来价格回填过去。

**参数**。内置原版默认周期为 5 分钟，`hl=6` 小时、`avgh=24` 小时，双向活跃成交保留权重 `eta=0.5`、主动卖出额外权重 `alpha=1`。48 小时是这条原版公式的保留窗口；半衰期决定近期与较早证据的相对权重，平均时长影响成交基线及波动尺度，三者不能混为一项。实际页面允许修改的内容，以该定义保存的公式和参数为准。

**使用**。在静态过滤、动态筛选或持仓监测里选择 CDA 时，必须同时核对方向、门槛和序列。例如 `CDA < 2` 会包含负值区域，并不等于“卖方阻力很小”；若想表达阻力减弱，要先按当前符号解释条件，再用样本检验门槛。原值、普通均值和加权均值回答的时间尺度不同，不直接互换数值。

**版本**。“CDA｜版本2”等近期加权副本有独立公式与身份，不能因为名称相近就当作原版。当前 CDA 原版公式本身不需要 BTC；是否依赖 BTC，应看所选完整公式，而不是按所有卖方指标一概判断。

## 4.8.3 状态 S

**定义**。状态 S 把买卖双方的优势放到一套对称框架里，最终映射到 0～1。它综合三部分：CBI-2 的买方/卖方对称分、买卖双方都加权的推力 az、买卖双方的定价保留。

| 部分 | 观察什么 | 内置原版的处理 |
| --- | --- | --- |
| 买卖对称分 Lcs | 买方与卖方模型分数的相对优势 | 对数几率之差的一半，再按 4 小时半衰期平滑 |
| 推力 La | 成交支持下的价格推动是否偏向某一方 | 主动买或主动卖都加权；按收益波动缩放，再乘 10 并截到 −3～3 |
| 定价保留 Lb | 买方与卖方此前形成的价格优势，到当前还保留多少 | 买方取较低价、卖方取较高价分别重估，平均后截到 −3～3 |

**公式**。设 `p`、`ps` 分别为买方、卖方模型分数，`Sb`、`Ss` 为两侧定价保留分量：

```text
Lc = [ln(p / (1−p)) − ln(ps / (1−ps))] / 2
Lcs = EMA(nz(Lc)，半衰期 sh=4 小时，初值 0)
La = clip(10 × az, −3, 3)
Lb = clip((Sb + Ss) / 2, −3, 3)
L = 3 × Lcs + 0.4 × La + 1 × Lb
状态 S = 1 / (1 + exp(−L))
```

内置原版合成权重是 **3 / 0.4 / 1**。这里的 az 是状态 S 内部的买卖对称推力，不能直接用仅对买方加权的某条 DSP 显示值替代。完整公式还规定了数据缺失的处理与各分量的基线，修改时不能只抄最终合成式。

**读数**。越接近 1 越偏买方，越接近 0 越偏卖方，0.5 是模型均衡点。S=0.8 不代表后面上涨概率是 80%，S=0.2 也不代表下跌概率是 80%。图表上的 **0.6 参考线**是显示约定，与模型的 0.5 均衡点不同，也不会自动替你勾选某个筛选条件。

**参数**。原版默认周期 5 分钟，通用 `hl=6` 小时、`avgh=24` 小时；对称分另有公式中的 `sh=4` 小时，推力尺度 `ka=10`。`hl` 与 `sh` 不是同一个平滑参数；改变合成权重、平滑或周期后，应作为不同口径重新核验。

**使用**。状态 S 可以作为买前必要条件、指标准入、加仓方向条件或持仓退出条件，但角色不同，条件关系也不同。例如在必要条件里是“同时满足”，在 v7 的新事件准入里可与防守线新事件构成“或”；不能因为某一路准入通过，就跳过其他必要条件与否决。数值高也不能代替加仓位置、距离、风险预算或真实持仓检查。

**版本**。状态 S 原版的 CBI-2 分量使用对齐的 BTC 数据；“无 BTC”是独立副本，用标的自身动量替代该部分的 BTC 调整。S2 则把定价保留部分改为 CDA 对应的有符号保留项，合成权重为 **3 / 0.4 / 3**；S2、S 的近期加权版本、无 BTC 版本各自独立，原阈值和模板不自动迁移。

## 4.8.4 DBL-5

**定义**。DBL-5 是已收盘 5 分钟达瓦斯箱体的工程实现。箱体给出确认后的上轨 U、下轨 D、确认时间与事件；防守线是在箱体之上另外维护的价格参考线。先认识“箱体完成”，再判断防守线是否建立、处于什么状态、是否断裂。

**箱体形成**。默认 `n=3`，几何证据窗口为 360 分钟。局部新高必须严格高于此前 n 根最高价，之后独立观察箱底；新高那根的最低价不直接充当箱底。上边界等待后续连续 n 根最高价严格低于 U；再次碰到 U 会重置这一等待，超过 U 则取消该候选。箱底的新低或同低会重置其确认起点；上下边界都完成后才发布并冻结箱体。

候选不等于可用箱体。确认后才能使用，不能把确认后的结构倒填到种子时点，冒充当时已经知道支撑在哪里。同一时点多个箱体完成时，由原引擎按已保存规则选择，不是每出现一个候选都触发交易。

**事件与失效**。相邻所选箱体可形成基准、完整上移、内部箱底抬高、同底新箱。箱体最低价严格低于下轨即破坏，影线也算；恰好触及下轨不算。几何证据到期从局部新高依赖的最早 K 线计时，**不是确认后再给 360 分钟**；缺口会重置箱体上下文。

**读数**。主值和上下轨有价格单位，宜在同一标的下解释；把高价币与低价币的绝对下轨直接汇总，得到的差异可能只是价格单位差异。跨币种研究可选“距下轨基点”“箱宽基点”“确认年龄”等独立维度，并核对各自公式、单位和取样时点。

**初始化**。研究页面可选择标的与回放起点。相同参数却使用不同起点、历史、tick 或数据修订，未必产生相同的已确认结构。默认可见研究窗口不等于只输入这段行情；初始化与预热必须完整保留。

### 4.8.4.1 防守线

**定义**。当前原生防守线版本为 `dbl5-guard-v1`，叠在 `dbl-5-v2` 箱体上，用 ATR 给箱底留出冗余。上涨期是蓝色实线，震荡期是蓝色虚线。首个可用箱体按震荡期建线；同一上涨段只升不降，震荡区内部的小箱体不会把线不断抬高。

交易页和交易战役的 DBL-5 盘面右下角，用淡色小字标明“防守线 · 趋势”或“防守线 · 震荡”，旁边保留一小段对应实线/虚线示意。标识取当前可见右端已经发布的结果，平移、缩放后随所见时点变化；历史各段仍按实线/虚线区分，十字光标可查看对应时点的详细状态。这里的“趋势”对应原生线的上涨期，不是把整张历史盘面统一划为某一种行情。

**参数**。默认上涨冗余 `a=0.5`、震荡冗余 `b=1`，采用已收盘 5 分钟 `ATR(14)`；上涨期 1 根、震荡期连续 2 根收盘严格低于原线，才确认原生防守线断裂。自定义参数以该方案/定义保存的值为准，不把当前默认值套回旧模板。

**公式**。D、U 是本次新确认所选箱体的下、上轨；D前、U前 是前一个所选箱体的边界；G前 是已有防守线；F 是震荡区保留的最低箱底；δ 是标的最小价格单位。

```text
取整价(x) = δ × floor(x / δ)
TR = max(H−L, |H−C前|, |L−C前|)；无前收盘时 TR = H−L
ATR(14)：前 14 个有效 TR 逐步取均值，随后 ATR = (13 × ATR前 + TR) / 14

O = min(U, U前) − max(D, D前)
上涨判定：D > D前，且 O ≤ 0.5 × min(U−D, U前−D前)
上涨期：G = max(G前, 取整价(D − a × ATR))
首次建线：按震荡期，F = D，G = 取整价(F − b × ATR)
上涨转震荡：F = min(D前, D)，G = 取整价(F − b × ATR)
已在震荡期：仅 D < F 时更新 F 与 G，否则保留原线
```

**何时更新**。ATR 至少有 14 根有效样本，且出现新确认的所选箱体事件，才按上式建线或更新。ATR 每根继续计算，但已有防守线不会仅因 ATR 变化而自行移动。结果不足一个 tick 时清空。

**何时断裂**。只看原生收盘确认：影线越线、收盘恰好等于线都不算断裂；收盘回到原线或上方，连续计数归零。箱体自身被影线破坏或到期，不会单独清掉已有防守线。每根已收盘 K 线先检查旧线，再处理新箱体，因此同根出现新箱体时可以重建。数据缺口或非法行情会断线；ATR 累计状态按原实现保留，前收盘衔接重置。

**三个用法要分清**。在动态筛选中，“防守线新事件”用于准入，首次产生、断裂后重建、上移/下移、实虚切换可按所选版本构成事件；同价同型延续不是新事件，断裂本身也不是准入。在加仓中，结构事件只是位置触发的一部分，仍须通过方向、距离、否决和预算检查。在退出中，原生收盘断裂与交易方案的 K 触价是两种执行口径：选择即时 K 触价版本时，可能在影线触价时退出，无须等待图表红叉。

因此，**箱体下轨、原生防守线、交易执行 K 三者不能混用**。看到图上仍有防守线，不足以证明某套交易方案不会先退出；看到原生红叉，也不能脱离该轮冻结版本推断实际卖出价。

## 4.8.5 其他

以下作简要识别。名称相近的特征值仍可能有不同公式、方向、单位和版本，使用前以该页保存的定义核对。

| 特征值 | 主要观察 | 阅读重点 |
| --- | --- | --- |
| DSP·a / DSP·az | 成交支持下的价格推动及漂移 | az 对单根收益做波动率缩放，不是最终指标自身的 Z 分数；与状态 S 内部对称推力区分 |
| BSS | 近期价格方向、成交量方向与主动买卖失衡的综合状态 | 是相对状态分，不是胜率；周期与近期窗口要匹配 |
| CBI / CBI-2 | 买方优势及主动性、动量、吸收等证据 | 两代公式不同；CBI-2 原版含 BTC 调整，模型分数需另行校准 |
| CBA | 历史成交支持形成的价格优势，到当前还保留多少 | 与 CDA 的买卖方向、当前价格取法不同，不能直接换名使用 |
| CBA-2 | 成交支持下的价格重心迁移 | 固定 5 分钟的独立实现，参数和预热按本页定义 |
| MBI / MBI2 | 买方优势及其趋势状态 | MBI2 可调日历时长，另有五档状态、持续时间；原版 MBI 保留 |
| CTBA / CTBA-12H | 趋势位置、VWAP 动能和主动成交金额的综合优势 | 12 小时版是独立副本，窗口、EMA 和权重分别保存 |
| 状态 S2 | 使用 CDA 定价保留分量的多空综合状态 | 与状态 S 的第三分量和权重不同，不能套用同一门槛 |
| CDI-2 | 买方控制向卖方转移的程度 | 当前卖方方向用负值表示；原版与无 BTC 副本独立 |
| 卖方控制力 DSP·bc | 卖方是否控制价格结果 | 主动卖出与被动压制都可体现，按收益 RMS 缩放；不同于旧 DSP·b |
| DSS | 动量、成交方向与主动失衡下的买方状态恶化 | 越低越偏卖方，衡量状态而非恶化速度 |
| MBI / MBI2 / CTBA 卖方系列 | 原趋势体系中的卖方优势 | 保留正负两侧，负侧可有独立增益；不是把正值直接截成零 |
| 定价保留副本 | 在来源指标上加入成交支持下的历史位移重估 | 来源公式、保留增量及合成增益都应核对，不能当作来源指标原版 |
| 近期加权版本2 | 提高近期证据在原计算中的相对权重 | 是独立公式与身份，不是简单把最终读数乘大；原阈值需重验 |
| 无 BTC 副本 | 以标的自身动量代替对应部分的 BTC 调整 | 保留各自来源参数，和原版独立；并非所有特征值都需要 BTC |
| ATI-6H | 买方确认、支撑、下行/成交方向、插针、阻力空间与突破保持六类证据 | 几何合成，某项为零会否决综合分；分数不直接控制加仓或止损 |
| PRS-6H | 固定结构、独立测试、更高防守与突破确认下的市场证据 | 0～100 分，账户余额和实际风险预算不进入分数 |
| SBS-5M | 经独立测试确认的台阶箱体支撑 | 横向箱体冻结后要测试成功；与 DBL-5 的确认、断裂和到期规则不同 |
| SBS / DBL 其他维度 | 支撑质量、标准化距离、台阶幅度、箱宽或年龄等 | 单位各不相同；不能把价格、基点、ATR 倍数和分钟数共用一个阈值 |

## 4.8.6 保存

**定义与结果分开**。编辑并保存定义后，旧研究结果仍是旧公式、旧周期、旧分组或旧取样时点的结果。页面出现“已修改”“请重新运行”等提示时，应先确认要研究哪套口径，再明确运行；不会因为读说明或生成图片自动重算。

**原值与均值分开**。图表、捕捞、批量挖掘、买前过滤和持仓监测使用同名定义时，还要核对选的是哪条原值/均值序列，以及该轮是否冻结了历史快照。修改当前账号定义，不等于能改写历史战役或已保存模板。

**图片与数据分开**。特征值标题旁“生成图片”导出当前名称、定义、完整公式和参数，不包含分组标准与统计结果。动态筛选、持仓监测设置里的同名按钮则导出对应完整条件设置，包含未保存的填写内容、各轮次与分支，优先一张长图。统计区的 CSV、统计图片和数据下载各有用途，不能把定义图片当成研究结果。

**先保留，再验证**。复用旧方案时，先核对其原文、参数、版本、指纹与生效范围。新能力应供明确创建的新方案或副本使用，不能用升级、重存、换默认值或重算指纹的方式消除真实差异。样本内差异、模拟利润或少量漂亮案例，都需要在匹配成本、仓位及执行约束后，继续用独立样本核验。
