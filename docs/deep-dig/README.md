## MBI·空方、CTBA·空方负向响应重写（2026-10-29，431 版）

- 取消旧版 `min(原指标, 0)` 的单侧截断。0 保持多空平衡；卖方优势为负，买方优势为正。MBI 原值及均值图使用 −1～1 刻度，CTBA 使用 −100～100，0 不再是上限。
- 公式为 `seller_response(x, seller_gain, scale)`，默认 `seller_gain = 2`，MBI 的 scale=1，CTBA 的 scale=100。x≥0 原样保留，x<0 为 `scale × tanh(seller_gain × atanh(x / scale))`；增益2等价于 `2x / (1 + (x/scale)²)`。MBI −0.5→−0.8，CTBA −50→−80；边界、缺失和零轴均保留。
- 不缩短任何响应窗口：MBI_N、MBI_Z0、CTBA 的 N/f/s/m/λ/权重、已收盘 5m、预热、24h 均值和6h分段加权均值全部保持原样。只提高零轴负侧的幅值响应；原来为正的数值不变，零轴穿越时刻不变。
- 账号中旧标准截断语句会原位升级，保留已有周期、参数及自定义均值；独立副本及已另写的公式保持独立，历史研究结果和捕获快照不覆盖。图表的手动周期及均值时长在本次公式升级时保留；之后显式修改周期参数仍会同步。
- CTBA 的 EMA 改用等价但数值稳定的递推写法，修正恒定成交均价下快慢 EMA 舍入残差被波动率分母放大、产生伪动能的问题；数学定义、窗口与权重不变。
- 新原值和两条均值共用 Deep Dig、指标图、捕捞、挖掘和监测的计算引擎。旧结果按旧公式保留，重新运行后使用新定义；负向增益是响应形状参数，不是下跌概率。

## 持仓监测条件加仓（2026-10-29，428 版）

### 定义（2026-10-16 用户要求：可以人为输入定义、公式、分组标准，运行时照这里算）

- **K 线周期、半衰期**（2026-10-16 用户要求「周期做成能够自主选择的，选哪个周期就统计哪个周期的变量；半衰期也要可以选」）：
  周期 `1m 3m 5m 15m 30m 1h 2h 4h 6h 12h 1d`，默认 5m；半衰期 1 / 2 / 3 / 6 / 12 / 24 / 48 小时或自定，默认 6 小时。定义区点一下就保存，旁边换算成「= 几根 K 线 · 观察窗多久」。
  公式在选定周期的 K 线上逐根算；`ema(x, h)` 的 h 按小时，换周期时自动换算成每根的衰减（ρ = 2^(−每根分钟数 / (h·60))），`prev / sma / sum` 按根数；公式里 `hl`（或「半衰期」）就是选的半衰期。
- **平均时长**（2026-10-17 用户要求「改成过去一段时间的平均值，时间选 24 小时，并且能修改；既可以在公式中改、也可以手动点击选取和填写」）：
  函数 `avg(x, h)` = 过去 h 小时（含当根）的平均，按周期换算根数（周期变了时长不变），空值跳过，开头不满 h 小时用已有的。
  参数 `avgh`（或「平均时长」）= 定义区点选 1 / 4 / 12 / 24 / 48 / 72 小时或自定，默认 24 小时；公式里也可以直接写数字，如 `avg(Q, 12)`。
  内置 V 的默认公式改为 `F = ln(1 + N / avg(Q, avgh))`（净资金比过去 24 小时的平均成交额异常多少）；以前的默认公式读进来自动换成这一版，旧结果提示重新运行。
  想与主图 DSP 逐根一致，把 `avg(Q, avgh)` 换回 `ema(Q, hl)`（单元测试核对这一版与 DSP 一致）。公式里没用到的参数，定义区旁边注一句。
  观察窗 = max(48 小时, 8 个半衰期, 平均时长 + 4 个半衰期, 50 根)；不是默认（5m、48 小时）时另取这个周期的币安 K 线算特征值，24h 结果与波动率仍按 5m。观察窗 K 线不到 95% 记缺失。
  周期、半衰期不是默认时才写进定义；改了算定义改动（提示重新运行）。上一版写死 `ema(·, 6)` 的默认公式读进来时自动换成跟随 `hl` 的版本，结果不变。
- **公式**（`src/lib/deepDig/formula.ts`，自己解析、不用 eval）：在进场前观察窗内的已收盘 K 线上逐根算，取最后一根。
  序列 `C O H L Q B S`（Q = 成交额、B / S = 主动买 / 卖成交额，USDT）；运算 `+ − × ÷ ^`、比较、`and or not`；
  函数 `ln exp abs sqrt sign max min prev ema(x, 半衰期小时, 初值) sma sum nz if has`；`名字 = 式子` 起中间量，最后一句是结果。
  用到 Q / B / S 时，有金额的 K 线不到 95% 记缺失。写错时提示第几行、哪里不对。
- **分组标准**：先选样本来源，再写实验组、对照组各一个条件：
  - **交易战役**：每场战役一个事件（时间点 = 进场时刻），条件里直接写「指标字母表」的字母，如 `c > 10 and b > 2`；
  - **信号库**：信号库里每条信号单独一个事件（时间点 = 那条信号的时间），与交易战役无关——没有战役记录的信号照样纳入；同币 48 小时内的几条信号**不合并**（战役才合簇）。读数 `s` = 星级（没评分 = 缺失），如 `s >= 4` / `s <= 2`；探顶区、写着事后结果的跟进记录、没有行情的信号不进样本。
  - 旧写法（`b` 理论 b、`r` 盈亏比、`pnl`、`chg`、`wear`）读进来时自动换成新字母（`Bₜ`、`b`、`p`、`c`、`w`），意思不变。
  同时满足 → 冲突；用到的读数缺失、未结算、校正未拉齐 → 其他战役；都不进两组比较。编辑时即时预览本机战役各组多少场。
  分组标准除了在「编辑定义」里改，定义区的「分组」与描述统计的「分组」两处都可以点「改标准」就地改。
  指标表（可用的字母）多一列本机范围（2026-10-18 用户要求「我想知道每个指标可以输入的数值范围」）：按本机样本算最小 ~ 最大、中位数、有读数 / 总数；整列没有读数的写「没有读数」（用它分组全归「其他」）。单位与写条件一致（% 写 10 = 10%）。
- 内置「多空博弈均衡点漂移速度 V」的 ema 版公式与主图 DSP 的 V 逐根一致（默认公式现在用过去 24 小时平均成交额，见上），默认分组标准（`b > 3 or r > 3` / `b < 0.5 or r < 0.5`）与原 Deep RSA 分组逐场一致（单元测试核对）。
- 定义（改过的内置项、新增项）存 `usePersistedState('deep_dig_features_v1')`，跟账号同步；定义改过后，旧结果上方提示重新运行。

### 第二个特征值：BSS 买卖强度综合分（2026-10-18 用户要求）

`BSS_DEF`（`src/lib/deepDig/features.ts`）：M = 近 n 小时涨跌幅（`ago(C, n)`），V = 近 n 小时平均成交额 ÷ 近 avgh 小时平均，A = (主动买 − 主动卖) ÷ 合计；M、V 标准化 = `tanh(zscore(·, avgh))`；**BSS = 0.45·Mz + 0.25·Vd + 0.30·A**，−1 ~ 1；`Vd = if(M > 0, Vz, if(M < 0, min(-Vz, 0), 0))`——2026-10-18 用户要求「放量随价格方向加减分」，随后改为「涨时放量加分、缩量扣分；跌时放量扣分、缩量不加分」：涨时 Vd = Vz，跌时放量 Vd = −Vz、缩量 Vd = 0，M = 0 时为 0（最早 Vz 不分方向，下跌放量也加分；第一版 `sign(M) * Vz` 跌时缩量也加分）。用户存过的 BSS 定义（两种旧写法）自动换成现在的写法（`upgradeBssFormula`，自己加的行原样保留），定义键随之变化，界面提示重新运行描述统计。
订单簿 I 没有历史数据，去掉（用户确认），权重按用户给的 0.45 / 0.25 / 0.30。标准化窗口 = 平均时长 avgh（默认 24 小时），近期窗口 n 写在公式第一句（默认 1 小时）。
K 线图指标菜单里的同名副图用 `src/lib/bss.ts` 的 `computeBss`，与这条公式逐根一致（`src/lib/__tests__/bss.test.ts`）。为此公式新增函数 `ago(x, h)`（h 小时以前的值）、`zscore(x, h)`（滚动标准化）、`tanh(x)`。

### 推断统计的命令（2026-10-16 用户要求：运行前给出命令行、可选方法、可自己设计方法）

## 第三个特征值：CBA 买方定价优势指数（2026-10-18 用户要求）

用户要求「新增一个指标 CBA…放在指标中、以及 deep dig 的第三个特征值」（az 顺延为第四个）。`CBA_DEF`（`src/lib/deepDig/features.ts`），K 线图同名副图用 `src/lib/cba.ts` 的 `computeCba`，单元测试核对逐根一致，并另写一份照笔记逐项直接算的版本核对。

- CBAₜ = 100·tanh(Σ_{i∈Wₜ} wᵢ,ₜ·Fᵢ·Gᵢ·Rᵢ,ₜ)，Wₜ = 截至当前的 48 小时；wᵢ,ₜ = 2^(−ΔT/h) 归一化；Fᵢ = ln(1 + (|D| + η(V − |D|)) ÷ V̄ᵢ₋₁)；Gᵢ = 1 + α·max(A, 0)；Rᵢ,ₜ = ln[min(Eₜ, Cₜ) ÷ Eᵢ₋₁] ÷ ((t − i + 1)·σₜ₋₁)。
- 取定：h = hl（默认 6），η = 0.5、α = 1（写在公式里），V̄ = `prev(avg(Q, avgh))`，σ = `prev(sd(ln(E / prev(E)), avgh))`；缺数据那根这一项记 0。

## 买方推力漂移速度 DSP·az（Z 分数版）

2026-10-18 用户要求「把 DSP 也做成可以基于 Z 分数的，具体哪一步需要标准化处理，你来定」。第三个内置特征值，K 线图「动态谢林点」打开「Z」开关时 a / avg_a 副图画的就是它。

- 只标准化价格变化：`Rz = R / sd(R, avgh)`（R 除以它过去 avgh 小时的样本标准差，均值按 0）。资金力量 f 本来就是和自己的平均成交额比、A 本来就在 −1 ~ 1，只有 R 带着各个币自己的波动大小；不减滚动均值——减掉会把要测的趋势本身减掉；也不对 a 本身做 z-score——那样 0 不再是多空平衡。
- 其余与 a 相同：`F = nz(f * G * Rz)`，`az = ema(F, hl, 0)`；显示 × 100，单位 % 标准差 / 根。
- 主图 DSP 线仍用原始 a（它是价格）。把 f 一行换成 `ema(Q, hl)` 与主图 Z 版逐根一致（单元测试核对）；波动放大 3 倍时原始 a 约放大 3 倍、az 几乎不变（单元测试核对）。
- 新函数 `sd(x, h)`：过去 h 小时的样本标准差（含当根，空值跳过，少于 2 个记空）。

## 第五个特征值：CBI 买方优势指数（2026-10-18 用户要求）

用户要求「新增一个指标 CBI…放在指标中、以及 deep dig 的第五个特征值」。`CBI_DEF`（`src/lib/deepDig/features.ts`），K 线图同名副图用 `src/lib/cbi.ts` 的 `computeCbi`，单元测试核对逐根一致，并另写一份照笔记逐项直接算的版本核对。

- CBI = P × D；D = (0.30·u_F + 0.30·u_A + 0.15·u_K + 0.25·u_S) ÷ 1；u = tanh(z ÷ 2)，z = (X − c) ÷ (1.4826·MAD)，c：F 取基线中位数、其余 0；u_S = ½[tanh(z_d/2) + tanh(z_v/2)]；P = RVᵏ ÷ (1 + RVᵏ)。
- F = Σw(Vᵇ − Vˢ) ÷ ΣwV；A = (λ⁺ − λ⁻) ÷ (|λ⁺| + |λ⁻|)，λ⁺ = [Σ_{x>0} w·r + κλ₀] ÷ [Σ_{x>0} w·x + κ]，λ⁻ 同理（− κ），x = (Vᵇ − Vˢ) ÷ V̄，r = ΔC ÷ ATR，λ₀ = Σ r·sgn(x) ÷ Σ|x|；K = Σw·V·CLV ÷ Σw·V；M = Σw·V·(H + L + C)/3 ÷ Σw·V，d = (C − M) ÷ ATR，v = (Mₜ − Mₜ₋ₘ) ÷ (m·ATR)。
