## 结构

- **目录**（`/journal/deep-dig`）：特征值列表，每项下面是三个模块的入口和一行摘要；底部「新增特征值」。
  删除特征值不常用，做得很隐形：鼠标移到那一项上才出现淡淡的 ×，点了还要确认；新增项连同结果一起删，内置项只是隐藏，目录底部可恢复。
- **特征值页**（`/journal/deep-dig/<id>`）：`?tab=` 选模块，`?g=` 选数据分组，`?all=1` 展开全部数据，`?edit=1` 打开定义编辑，都在网址上，从战役返回后回到原来的位置。

### 定义（2026-10-16 用户要求：可以人为输入定义、公式、分组标准，运行时照这里算）

- **K 线周期、半衰期**（2026-10-16 用户要求「周期做成能够自主选择的，选哪个周期就统计哪个周期的变量；半衰期也要可以选」）：
  周期 `1m 3m 5m 15m 30m 1h 2h 4h 6h 12h 1d`，默认 5m；半衰期 1 / 2 / 3 / 6 / 12 / 24 / 48 小时或自定，默认 6 小时。定义区点一下就保存，旁边换算成「= 几根 K 线 · 观察窗多久」。
  公式在选定周期的 K 线上逐根算；`ema(x, h)` 的 h 按小时，换周期时自动换算成每根的衰减（ρ = 2^(−每根分钟数 / (h·60))），`prev / sma / sum` 按根数；公式里 `hl`（或「半衰期」）就是选的半衰期。
- **平均时长**（2026-10-17 用户要求「改成过去一段时间的平均值，时间选 24 小时，并且能修改；既可以在公式中改、也可以手动点击选取和填写」）：
  函数 `avg(x, h)` = 过去 h 小时（含当根）的平均，按周期换算根数（周期变了时长不变），空值跳过，开头不满 h 小时用已有的。
  参数 `avgh`（或「平均时长」）= 定义区点选 1 / 4 / 12 / 24 / 48 / 72 小时或自定，默认 24 小时；公式里也可以直接写数字，如 `avg(Q, 12)`。
  内置 V 的默认公式改为 `F = ln(1 + N / avg(Q, avgh))`（净资金比过去 24 小时的平均成交额异常多少）；以前的默认公式读进来自动换成这一版，旧结果提示重新运行。
  想与主图 DSP 逐根一致，把 `avg(Q, avgh)` 换回 `ema(Q, hl)`（单元测试核对这一版与 DSP 一致）。公式里没用到的参数，定义区旁边注一句。
  观察窗 = max(48 小时, 8 个半衰期, 平均时长 + 4 个半衰期, 50 根)；不是默认（5m、48 小时）时另取这个周期的币安 K 线算特征值，24h 结果与波动率仍按 5m。观察窗 K 线不到 95% 记缺失。
  周期、半衰期不是默认时才写进定义；改了算定义改动（提示重新运行）。上一版写死 `ema(·, 6)` 的默认公式读进来时自动换成跟随 `hl` 的版本，结果不变。
- **公式**（`src/lib/deepDig/formula.ts`，自己解析、不用 eval）：在进场前观察窗内的已收盘 K 线上逐根算，取最后一根。
  序列 `C O H L Q B S`（Q = 成交额、B / S = 主动买 / 卖成交额，USDT）；运算 `+ − × ÷ ^`、比较、`and or not`；
  函数 `ln exp abs sqrt sign max min prev ema(x, 半衰期小时, 初值) sma sum nz if has`；`名字 = 式子` 起中间量，最后一句是结果。
  用到 Q / B / S 时，有金额的 K 线不到 95% 记缺失。写错时提示第几行、哪里不对。
- **分组标准**：先选样本来源，再写实验组、对照组各一个条件：
  - **交易战役**：每场战役一个事件（时间点 = 进场时刻），条件里直接写「指标字母表」的字母，如 `c > 10 and b > 2`；
  - **信号库**：信号库里每条信号单独一个事件（时间点 = 那条信号的时间），与交易战役无关——没有战役记录的信号照样纳入；同币 48 小时内的几条信号**不合并**（战役才合簇）。读数 `s` = 星级（没评分 = 缺失），如 `s >= 4` / `s <= 2`；探顶区、写着事后结果的跟进记录、没有行情的信号不进样本。
  - 旧写法（`b` 理论 b、`r` 盈亏比、`pnl`、`chg`、`wear`）读进来时自动换成新字母（`Bₜ`、`b`、`p`、`c`、`w`），意思不变。
  同时满足 → 冲突；用到的读数缺失、未结算、校正未拉齐 → 其他战役；都不进两组比较。编辑时即时预览本机战役各组多少场。
  分组标准除了在「编辑定义」里改，定义区的「分组」与描述统计的「分组」两处都可以点「改标准」就地改。
- 内置「多空博弈均衡点漂移速度 V」的 ema 版公式与主图 DSP 的 V 逐根一致（默认公式现在用过去 24 小时平均成交额，见上），默认分组标准（`b > 3 or r > 3` / `b < 0.5 or r < 0.5`）与原 Deep RSA 分组逐场一致（单元测试核对）。
- 定义（改过的内置项、新增项）存 `usePersistedState('deep_dig_features_v1')`，跟账号同步；定义改过后，旧结果上方提示重新运行。

### 三个模块（用户要求描述统计与推断统计分开运行）

| 模块 | 运行 | 内容 |
|---|---|---|
| 描述统计 | 单独运行：取币安 K 线（选定周期）、按公式算、按标准分组（联网，1–3 分钟） | 四组的 n、均值、标准差、中位数、四分位、> 0 占比；点阵图；细节；逐场数据（点一行打开战役；归类不准的行可整行删掉——× 平时隐形，鼠标移到那一行才出现，可查看恢复，删减跟账号走 `deep_dig_excluded_v1`） |
| 推断统计 | 单独运行：用描述统计的数据（去掉删掉的行），不联网，几秒 | 运行前先选方法、看 / 改命令（见下）；每条命令一张结果卡片；描述数据、删减或命令变了会提示重跑 |
| 规律提取 | 不用运行 | 默认按统计结果写出（`deepDigRules`），可以手动改（`deep_dig_notes_v1`，跟账号同步），可恢复 |

**时间序列曲线**（2026-10-17 用户要求「描述统计那里能够画出各组的时间序列曲线（组内数据在时间序列上的平均），比如 V 的时间序列曲线，并且这个变量可以让我来选择（默认为当前的核心变量）」）：
描述统计「分组」下面一块「时间序列」。每个事件把公式里每个变量，从进场前 24 小时到进场后 24 小时每小时取一个值（周期粗时前后各至少 12 根、点距 1 根），按组平均画线；实验组、对照组带 ±1 标准误阴影，随机时点用虚线。
- 每个时点 = 那一刻之前最后一根已收盘 K 线上的值；K 线往前多取 24 小时，每个点都有完整的观察窗历史（τ = 0 与特征值一致，只差观察窗以外那点残余权重，单元测试核对）。中间缺 K 线的点记缺失。
- 进场后的部分只作描述，特征值、分组、推断统计仍只用进场前的数据（为画曲线，K 线多取到进场后 24 小时）。
- 变量从公式里选，默认公式最后一句；删掉的行不算；悬停看各组在那个时点的值与样本数；「看数字」切到每 6 小时一列的表。
- 组别可以选取和删减（2026-10-17 用户要求）：「组别」一行逐组勾选（带样本数），去掉的组不画、不进表格和悬停读数，「全部显示」恢复；选择按特征值记在本机。
- 曲线约几 MB，存在本机 IndexedDB（`veil-deep-dig` / `series`），与描述统计结果对应；旧数据没有曲线，重跑描述统计后显示。

### 推断统计的命令（2026-10-16 用户要求：运行前给出命令行、可选方法、可自己设计方法）

`src/lib/deepDig/commands.ts`。方法勾选框：t 检验、排名比较、相关、五分位、回归分析、多元线性回归、方差分析、RSA、机器学习；勾上 = 命令里加一行默认写法，取消 = 删掉这个方法的行。命令窗口一行一个方法，可直接改、自己写，写错的行即时标红；命令按特征值存 `deep_dig_commands_v1`，跟账号同步。

| 命令 | 做什么 |
|---|---|
| `ttest(变量, 组A, 组B)` | Welch t 检验，附发现期 / 确认期 |
| `mannwhitney(变量, 组A, 组B, perm=1999)` | AUC、标签置换 p、按币整簇重抽样区间 |
| `spearman(变量, 结果…, control=vol, perm=1999)` | 发现集 Spearman + 月内置换 + Holm，控制变量的偏相关，确认集按同方向复核 |
| `quintiles(变量, 结果…)` | 五分位（切点取发现集）每档结果均值 |
| `regress(y ~ x1 + x2 …, in=组)` | 最小二乘：系数、标准误、t、p、95% 区间、R²、调整 R²、整体 F（与 numpy / scipy 逐位核对） |
| `anova(变量, 组…)` | 单因素方差分析：F、p、η²（与 scipy.stats.f_oneway 核对） |
| `rsa(变量 + …, 组别 或 结果, in=组, perm=199)` | 表征相似性分析：特征距离与组别 / 结果距离的 Spearman r，置换 p（单侧） |
| `ml(组 ~ 变量 + …, model=logistic\|knn, cv=5, k=15, in=组, perm=199)` | 分类模型，分层 k 折交叉验证的样本外 AUC、平衡准确率、打乱标签的置换 p |

变量：`X`（因变量，默认特征值，显示单位）、`vol`（观察窗波动率 %）、`endRet / maxUp / maxDown`（24h 结果 %）、`实验组 / 对照组 / 其他 / 随机`（0 / 1）；可以写成式子。组可以用 + 合并（`实验组+对照组`），`全部` = 四组。

**因变量**（2026-10-17 用户要求「推断统计的时候需要让我选择因变量…我不知道是不是选中了 VV 还是误选成了别的。因变量要源自公式框」）：
命令窗口上方一行「因变量」列出公式里起了名的每个变量（如 `N F A G R U V VV`），默认是公式最后一句（标「结果」），旁边写明 `X = VV（公式最后一句）× 10000 · 基点/根`。
点别的变量 = 命令里加一行 `X = F`（插在开头注释后）；点回最后一句 = 删掉这一行；也可以直接在命令里写 `X = F`。公式里没有的名字标红、不能算。
描述统计运行时把公式里每个变量在进场前最后一根的值都存下来（旧数据没有，选别的变量前要重跑描述统计；数据里没有时整份推断不算，不悄悄换成别的）。
X 按显示倍数（× scale）；公式里的变量也可以直接写进命令（原值），如 `regress(endRet ~ F + A)`。结果上方写「这次的因变量：X = …」，规律提取里推断的那几句用它的名字。
