# DBL-5防守线+急拉-1115

- 持仓监测 → 加仓细节 → 位置。逐轮分别配置箱体／指标位置、5 分钟急拉线和急拉线-1115。后两者也可以独立启用。同一轮同时符合时，按上述顺序评估，最多成交一次。已保存的 1115 组合位置继续用其原始版本。
- 独立位置 `holding-impulse-1115-position-v1` 复用 1115 的首次急拉检测。K 由当时有效的急拉参考提供，默认已含 0.5 倍前置 ATR 冗余，可单独设置最小距离。
- Deep Dig → 达瓦斯箱体 · 5m → DBL-5防守线+急拉-1115。价格研究选单一品种。事件下拉可定位首次急拉、破坏、到期、阶段和过伸，JSON 同时导出对照与检查点。CSV 输出组合价格、原防守价、急拉价、起点、基点距离和各事件字段。
- 战役图 → 5m → 指标 → DBL-5防守线+急拉-1115。绿色为原防守线，金色为组合线。正式标记放在收盘检测时点，点线回指冻结的起点所在 K 线，独立段之间断开。

## 有效参数与时点

独立版本 `dbl5-guard-impulse-1115-v1` 使用 5m 已收盘 K 线和整数报价格点，无 BTC 依赖。开盘时间表示窗口起点，收盘时间表示首次可用时刻。急拉低点是已观察窗口的最低价，尚不代表回踩验证。

取起点前 ATR(14)，至少 14 个、最多 68 个前置收盘增量。正向增量指数加权，半衰期 12 根，非上涨样本计入分母。逐根从最早的 1–3 根候选找首个合格运动窗口。净位移至少 1.2 ATR，每根速度至少 0.8 ATR 和常态的 1.5 倍。净实体占真实波幅至少 0.65，净涨幅占最大上涨距离至少 0.80，当前收盘高于开盘和昨根收盘。局部突破要求比起点前三根最高价多至少一档。成交量为 K 线基础币量，相对量缺失时为空。

两根整理的高低范围包含整理前收盘，至多为 1 倍整理前 ATR。下一根进入新阶段。若窗口位移或阶段最高位相对锚点超过 3 ATR，锁定过伸。首次事件冻结窗口低点减 0.5 倍前置 ATR，再向下取报价格点。急拉一根收盘严格跌破即失效，影线独立记录。起点满 360 分钟到期。较低的新急拉保留证据，旧有效线及原到期时间继续有效。

## 输出与执行

`DBL5` 保留旧箱体下轨。新的 `DBL5P` 为组合参考，`DBL5P_base`、`DBL5P_impulse`、`DBL5P_origin` 分别提供原防守线、急拉线和起点。来源 `BOTH` 表示两条线同价。阶段为起点未知、观察起动、待突破、首次检测、等待新整理、过伸、窗口结束和破坏。阶段切换从下一根起生效，阶段状态与仍有效的线价可独立存在。

已有箱体触发与所选轮次的首个急拉事件都能进入原加仓评估，同一时点最多形成一次加仓。方向、否决、定量、最小距离、保本底线和已选止损执行版本沿用该方案。由急拉线提供 K 基准时直接使用已含冗余的参考。既有成交的冻结 K 不随组合换段放宽。

Deep Dig、图表和持仓加仓使用同一顺序计算实现。持仓分批计算用独立检查点，研究可导出检查点和参数。历史修订需要按修订后的数据顺序重放。加仓成交证据与现时读数沿战役现有 JSON 字段保存，持仓战役导出中可查。

实时跟单以战役和固定急拉事件标识去重。急拉收盘到下一根 5m 收盘之前可投递，过时事件留在研究或模拟证据中。币安本机执行器需返回 `guardPlusAdditions: 1`，旧执行器在配对后仍处理已经支持的方案。真实跟单成交以币安成交回报为准。
