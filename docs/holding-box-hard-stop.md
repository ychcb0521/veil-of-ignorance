# 持仓监测：箱体硬性终止 v1

入口：「持仓监测 → 条件设置 → 硬性终止 → 添加箱体终止」。新增行默认不启用，由用户选择算法、参数和成交规则，应用或保存后随对应账号方案、模板保留。各次加仓后的否决编辑器也可使用该条件。旧引擎方案继续保持只读，不自动升级。

可选项：

| 设置 | 选择 |
| --- | --- |
| 箱体算法 | DBL-5 v2、SBS-5M v1 |
| K 基准 | 当前确认箱底；DBL-5 防守线；SBS 失效线 |
| 额外冗余 | ATR(14) 倍数或基准价格百分比 |
| K 更新 | 首次有效 K 固定、只升不降、跟随最新结构（允许下移） |
| 终止确认 | 触碰 K 立即全仓卖出；1 分钟或 5 分钟收盘确认 |
| 连续根数 | 收盘确认时由用户填 1–100 根；K 改变后重新累计 |
| 箱体细节 | DBL 确认 n、几何窗口及防守线参数；SBS 原生全部数值参数与成交量口径 |

触碰模式与收盘模式是不同选择。触碰模式读分钟最低价，低于或等于 K 即模拟卖出所有剩余仓位（包括加仓）；开盘已经越线按当时开盘价成交，否则按 K。收盘模式只累计指定周期的已完成收盘，达标后按下一分钟开盘价成交；下影线触碰不代替收盘。该条件不要求镜像止盈或实际加仓已发生，也不更改原加仓 K、定量或原有止损。

结构只使用当时已收盘的原生 5 分钟线，当根尚未确认的箱体不能回头止损之前的影线。尚未有有效结构时等待，不虚构 K；已经设置的 K 在箱体失效或防守线清空时仍继续保护，直到按所选方式更新或触发。实际行情缺口或无效报价精度报错，不能静默越过。

初始化沿用已有结构方案的历史要求与真实报价元数据；图灵杯专用方案继续按已冻结的 `turing-origin-v1` 初始化。暂停续算保存 K、确认时间和根数；分段切换只采用实际切换时点已知的状态，丢弃随后预扫描状态。

依赖：本标的原始 OHLC、箱体所需成交量/成交额、历史报价步长、已收盘时间，及已有盘面 ATR(14)（EMA 真波幅公式）用于额外冗余。新增箱体终止自身无 BTC 依赖。原方案其他指标若依赖 BTC，依赖仍保留，未被静默替换。

原生 DBL-5、SBS-5M、防守线算法与锁定输出均未修改。新增执行版本为 `holding-box-stop-v1`；配置保存时冻结原生算法版本、全部有效默认参数和用户参数，并纳入运行身份、模板版本清单。未启用新条件的旧方案沿用原身份与原执行路径。

合成验证对比（不是最新 RAVEUSDT 战役复盘）：入场价 100、有效 K=90，某分钟开盘 100、最低 90、收盘 99，触碰模式在该分钟按 90 卖出；收盘模式不会因该影线触发。若开盘跳到 80，触碰模式按 80 成交。两根 1 分钟收盘均为 89、下一分钟开盘 85，连续两根确认模式按 85 卖出。固定模式和只升不降模式不会随随后下移的箱体将 K 从 90 放低至 80；允许跟随模式可以。
