# MBI2 与 CTBA-12H 的独立卖方特征

## 选择入口

Deep Dig 特征列表、图表「自制区」、渔的探测条件、持仓监测卖出条件都复用同一份特征定义。

| 名称 | feature_id | 核心输出 |
| --- | --- | --- |
| MBI2 迈克尔买方优势（可调版） | mbi2 | MBI2 |
| MBI2 卖方趋势（可调版） | mbi2-bear | MBI2_bear |
| CTBA-12H｜趋势买方优势（12小时） | ctba_12h | CTBA |

## 卖方响应

沿用现有 MBI/CTBA 空方版的负向增益函数：正值不变，0为综合均衡，负值增强。默认 seller_gain=2，可在各自公式中修改。

设原始读数为 v，尺度为 S（MBI2为1，CTBA-12H为100），则：

- v ≥ 0：输出 v。
- v < 0：输出 S × tanh(seller_gain × atanh(v / S))。
- 缺失保持缺失，不用0替代。

默认增益为2时，−0.5变为−0.8，−50变为−80。正值仍可大于0，不截断到0，也不翻转符号。增益不改变任何测量窗口。

## 独立参数与状态

MBI2的小时参数换算 n=max(5,round(T_HOURS×60/周期分钟数))。未手动设置小时数时，各周期默认n=25；手动设置后保持日历时长。z0固定1.25，缓冲带默认0.2，确认阈值默认0.8，预热5n根，分析窗48小时。卖方副本的状态及本轮/确认持续小时根据增强后的卖方读数独立生成，状态 −2 表示卖方确认。

CTBA-12H卖方版保留5m、N=144、EMA8/24、波动窗口48根、主动成交半衰期24根及0.35/0.40/0.25权重。研究窗12小时、144个已收盘采样点。均值可以额外读取预热历史，不缩短或替换这144个点。图表固定显示对称零轴，提示保留T、M、F。

新旧特征拥有不同ID、公式、缓存上下文与参数版本；修改或运行副本不覆盖原特征的配置和历史结果。修改后的结果按各自公式重新计算。
