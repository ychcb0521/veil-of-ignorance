# Deep Dig 特征创建时间

目录每个特征名称行右侧显示创建时间（北京时间，精确到分钟）；悬停显示秒和来源。窄屏另起一行，原复制、删除和三个模块入口保留。

新建、自定义复制使用已有的createdAt记录，仍随原账号定义同步。修改、改名和保存不能覆盖或丢失已记录的创建时刻。没有可靠记录的历史自定义特征显示「创建时间未记录」，不以当前加载、保存、同步时间补填。

内置特征的原始创建时刻未完整记录；以Git中该特征首次注册到项目的提交时间为版本依据，在界面明确标注「版本记录」，悬停可见提交编号。可追溯内置项的来源集中在src/lib/deepDig/featureCreation.ts；新增内置项时维护该表。确定性复制构造中的固定日期仅是ID种子，不冒充真实创建记录。隐藏、恢复、账号修改与重新同步均不改变此版本来源。

此次只增加目录元信息展示和保存时的时间保护。公式、参数、特征ID、排序、计算缓存编号和研究结果不改；版本依据只用于展示，不回写到原内置定义或历史数据。
