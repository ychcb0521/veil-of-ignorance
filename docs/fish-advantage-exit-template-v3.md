# 鱼质量·优势筛选与退出灵敏度 v3

入口：鱼质量 → 持仓监测 → 条件设置 → 从模板新建。新版列在内置模板首位。选择沿用的已保存方案或账号模板；也可直接选择「内置原方案 · 结构为底·强势进攻（RAVE×SAPIEN 融合）」。无账号来源时默认显示内置原方案，多个账号来源时须明确选择，按钮保持可点击并在缺少选择时就地提示。内置路径完整沿用融合原版参数，不冒充 A/B 的账号设置。新建后保存全部方案；需要时继续存为账号模板。不会自动运行监测或替换正在运行的方案。

代码中没有此前 Excel 的“结构限额 v2”。此版把修正后的方向落地到应用，历史内置模板保留供比较。

## 保持什么

完整复制原方案的公式快照、镜像比例、逐轮方向/位置门槛、K/ATR、平衡定量、最大轮数、减仓版本、进攻分支及分段退出条件。不把 A/B 导出中缺失或冲突的设置拼成猜测版本。

平衡式仍为 `Q×(K−S)+P＝新增币数×(T−K)`。只判断是否接受本次机会，不给数量打折，不新增仓位上限，不改变 K 来间接缩量。106 条导出事件用原生产计算函数复算，作为定量回归样本；这不是新策略回测。

## 何时调整

| 当时可见状态 | 本次加仓 | 软退出 | 硬退出 |
| --- | --- | --- | --- |
| 三根完整 5m 线，收盘价与状态 S 均连续两次下降（W） | 原条件通过后跳过该次机会 | 原单次 | 原规则 |
| 未加仓，DBL-5 有效、非 W | 原量 | 连续两根完成的 1m 读数确认 | 原规则 |
| 已加仓，DBL-5 有效、S 不下降、收盘突破前两根最高价（A） | 原量 | 连续两根完成的 1m 读数确认 | 原规则 |
| 已加仓，非 A、非 W（B） | 原量 | 原单次 | 原规则 |
| 新辅助行情不足（U） | 回退原条件并记录缺失 | 原单次 | 原规则 |

W 仅需价格与状态数据；缺少 DBL 辅助数据不能抹去已确认的 W。原方案必需行情缺失仍按原规则报错。

拒绝不推进成功轮次、不消耗镜像余额，下一次按原扫描时机判断。B 无须先变 A 才能加仓。每次只使用最新完整 5m 数据，优势等级不永久锁定。

软条件不成立、分钟缺口、指标/阶段切换会重置确认；单纯加仓不会清除待确认读数。已确认软退出优先于同刻新增加仓。原 K、回撤、急跌及减仓不经过两根确认。回放在每次实际加仓处切分，后续仓位不能影响更早退出；续算保留确认状态。

W 筛选、首加前确认、加仓后确认各有独立开关；确认数可选 1 或 2。先分别对照，再组合评价。

## 依据与不确定性

来源：用户提供的 `鱼质量-20261105225743.xlsx`（A）、`鱼质量-20261105225757.xlsx`（B），不是新版运行结果。

- 86 笔共同已完成交易中 84 笔盈亏一致；总盈亏约 24,540.74 / 36,588.73 USDT。差额主要来自 SAPIEN 的更大加仓，这是保留放大机制的依据，不能据利润集中推导应限制加仓。
- A 的 23 笔可分类算法退出中，10 笔被表内标为卖后 6h 误报，全部未加仓，支持优先研究首加前软退出敏感度。该比例只描述导出的这部分分类记录。
- A 第 983 行 LISTA 状态约 0.500915 → 0.498883，卖后 6h 最高上涨约 37.59%；第 1010 行 VIRTUAL 约 0.501055 → 0.497232，卖后最高约 6.85%。轻微越线值得研究确认机制；卖后最高价不是可实现收益。
- A 第 958 行 RAVE 最后加仓后 1 分钟退出，需研究当时可见的弱化和响应，不能用未来一分钟信息否决上一分钟加仓。
- A 的 14 笔 K 退出缺少卖后 6h 数据，不能据此认定 K 太紧，因此保留原 K。

两次同步下降与两根确认均为未验证假设。工程测试证明执行与兼容性，不证明收益提高。A 有版本记录缺失，B 的 RAVE 配置描述与事件冲突；原表没有完整费用和资金约束。

此前草案的净利润回吐保护（峰值至少 2 ATR 金额、回吐达到峰值 30% 与 1 ATR 金额的较大者）本版暂不启用。手续费、滑点、资金费及逐时点现金流未接入前，不得拿毛利润冒充净利润，也不得用最终仓位乘早期峰值。现有退出保护继续运行。

## 如何验证

1. 复现原方案；同一数据、成本和资本约束下分别只开 W、只开首加前确认、只开加仓后确认，再组合。
2. 比较净收益、资金需求、首加及后续加仓参与率、延迟退出额外损失、拒绝机会后果；单列 SAPIEN/RAVE 是否错过放大链。
3. 完整重放后续路径，不能固定原加仓记录后套新卖出时间。86 笔已参与设计，不能当独立测试集。
4. 冻结候选后，在未见时间段和标的上验证，不只挑最高收益参数。
