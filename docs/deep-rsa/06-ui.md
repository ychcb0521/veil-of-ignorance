# Deep RSA · 第 6 步：复盘中心入口

- 入口：复盘中心菜单里「规则」**正下方**、与之并列的「Deep RSA」，路由 `/journal/deep-rsa`（写在 `/journal/:id` 之前，不会被错题集回放页吞掉；错题集的高亮判断也排除了这条路由）。
- 页面：`src/pages/JournalDeepRsaPage.tsx`（取数）+ `src/components/journal/DeepRsaView.tsx`（展示）。
- 只读：不改原有功能和交易逻辑，不自动实盘，不写任何数据。

## 页面内容

1. **进度**：六步各自的状态与文档。
2. **暂定分组**：直接取交易战役列表同一份缓存行（与列表 / Excel 同一个数），逐场按第 2 步规则分组；给出各组计数、理论 b 与盈亏比两种口径各自的条件分布、待判定原因、同标的 48h 去重后的簇数（及簇内一正一负的簇数），并列出所选组的战役。
   - 平仓价校正是否拉齐在列表缓存内部、本页看不到，**按已拉齐处理，整组标「暂定」**；正式分组需核对校正状态。
   - 列表行没有「本地从未成交的委托 id」：锚点 B 只取有成交记录或本来没挂成交 id（回填）的 main_open 腿。
3. **特征**：15 个特征的公式，直接读代码里的定义表（与实现同一份）。
4. **结论**：每条标「已验证 / 待验证 / 检验未获支持」及依据。
5. **还缺什么**。

## 操作

- 分组筛选写在 URL（`?g=`），换筛选不新增历史记录。
- 点战役进详情前记下滚动位置；详情页按「退回上一条历史记录」返回，回到原筛选、原位置。
