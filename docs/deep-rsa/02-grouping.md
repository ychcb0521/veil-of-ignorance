## 1. 交易战役

| 组 | 条件（严格 OR） |
|---|---|
| 正样本 | 理论 b **>** 3 **或** 盈亏比 **>** 3 |
| 对照组 | 理论 b **<** 0.5 **或** 盈亏比 **<** 0.5 |
| 冲突组 | 两边同时触发（例：理论 b = 4、盈亏比 = 0.3），单列，不并入任一侧 |
| 中间组 | 两个条件都落在 [0.5, 3]（**等于 3 不算正样本，等于 0.5 不算对照**） |
| 待判定 | 见下表任一原因 |
| 排除 | 回收站战役、主空战役 |

- 盈亏比 = 已实现盈亏 ÷ L₀（初始预期最大亏损），直接相除，不经 ×100 往返。
- 理论 b = 几何仓位（理论）× 相对涨幅，复用 `computeMagicB`。没有成交加仓的战役结构上没有理论 b，记 **na**（不是缺失），只按盈亏比分组。
- 两个口径**分别计数**（`conditionBreakdown`），报告时分开列。
- 锚点用 B（最早成交 main_open 的 `pre_simulated_time`）；A、D 同时保存供敏感性分析。B 取不到时不自动换口径，判待判定。

**待判定原因**（缺失不当作 0）：

| 代码 | 含义 |
|---|---|
| `unresolved_status` | 战役未结束 |
| `no_anchor` | 取不到锚点 B |
| `payoff_basis_weak` | 盈亏比分子来自落库缓存或无数据 |
| `invalid_l0` | L₀ ≤ 0.0001 |
| `corrections_incomplete` / `corrections_unknown` | 平仓价校正未拉齐 / 不知道是否拉齐 |
| `condition_missing` | 理论 b 应有却缺，或盈亏比缺 |
| `no_condition_known` | 两个条件都不可用 |

另记 `l0IsLowerBound`：多主力且有不出保护线的敞口时 L₀ 是下限、盈亏比偏高，报告时单独标出。

## 2. 信号库

- 星级 ≥ 3（**三星算**）→ 正样本；1–2 星 → 对照组。
- 只接受 1–5 的整数；未评分、0、越界、非整数 → 待判定（不沿用界面的四舍五入）。
- 排除：不可跳转（无行情）、谢林兜底区写「探顶区」、兜底区里写着「触发 / 涨至」这类事后结果的跟进记录。
- 星级没有评分时间戳，无法证明评分时不知道后续走势——第 1 步 §7 已列为风险，信号库结果与交易战役结果分开报告。

## 3. 同一行情去重

- 同标的、锚点相距 **< 48 小时** 的事件单链串成一簇（`clusterEvents`），簇代表取最早一条；统计检验以簇为单位，不把簇内多条当独立样本。
- 簇内一正一负记为标签冲突（`clusterLabelConflict`），单独报告。

## 4. 随机背景时点

- `sampleBackgroundAnchors`：固定 seed 可复现，落在 5 分钟整点，丢弃与同标的事件锚点相距不足 48 小时的候选点。
- 背景时点**不假设为失败样本**，只作为「普通时刻」基线。
