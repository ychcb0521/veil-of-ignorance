# Deep RSA · 第 5 步：样本外检验、扫描、基线与交易回测

> 状态：**流程已写成代码并有单元测试；没有在任何真实数据上跑过，没有任何收益数字**——缺你的 Supabase 导出与币安行情（含资金费历史）。纯离线模拟，不下单、不接实盘。

代码：`src/lib/deepRsa/scan.ts`、`backtest.ts`；测试：`src/lib/deepRsa/__tests__/backtest.test.ts`。

## 1. 顺序（不可颠倒）

1. **冻结**：第 4 步在训练集上定表征、在验证集上定半衰期 h；这里再在训练集上拟合模型，在验证集上定阈值。全部写死后才碰测试集。
2. **样本外 RSA**：用训练集的标准化参数，在测试集上重做第 4 步的 Mantel 检验（只检验第 4 步通过 Holm 的那几项，Holm 族按这几项重算）。方向与训练集一致且显著，才进入下一步。
3. **扫描**：在测试期内对每个标的逐 5m 打分，过阈值发信号；同标的一次信号后冷却一个结果期（24h），持仓不重叠。
4. **回测**：模型与基线在同一时间段、同一标的池、同一出场规则、同一成本下比较。
5. 测试集只读一次；敏感性分析另列，不用来挑最好看的一组。

## 2. 模型（RSA 通过之后的应用，不是 RSA 本身）

- 训练集上：表征特征标准化，算正样本中心、对照组中心。
- 打分 = 到对照中心的距离 − 到正样本中心的距离，越大越像正样本。**分数不是盈利概率。**
- 阈值 = 验证集分数的 80% 分位数；有效分数不足 5 个则不定阈值、不往下做。

## 3. 基线

| 基线 | 规则 |
|---|---|
| 定期买入 | 不挑时机，冷却期一过就买（衡量「这段时间做多本身」赚不赚） |
| 48h 动量 | ln(C_N / O_1) 过阈值就买（阈值同样在验证集上定） |
| 随机背景时点 | 第 2 步的背景锚点，按同一出场规则交易 |

模型只有在**扣成本后稳定优于全部基线**时，才谈得上「有用」。

## 4. 交易规则与成本（事先固定）

| 项 | 默认 | 说明 |
|---|---|---|
| 进场 | 信号后第一根完整 5m K 线开盘 × (1 + 滑点) | 进场那根缺行情 → 不成交，单独计数 |
| 出场 | 24h 到期，最后一根收盘 × (1 − 滑点) | 可选止损 / 止盈；同一根 K 线两者都碰到 → 按止损 |
| 跳空 | 开盘已越过止损 / 止盈价 → 按开盘价成交 | 不假装在挂单价成交 |
| 手续费 | 每边 0.05%（应用的吃单费率 `TAKER_FEE`） | |
| 滑点 | 每边 5 个基点 | 敏感性：0 / 5 / 10 个基点 |
| 资金费 | 真实资金费历史，按持仓期间的结算时刻扣 | 缺真实数据时按应用常数 0.01% / 8h，并在汇总里计数 `fundingAssumed` |

## 5. 报告指标

交易数、未成交信号数、平均 / 中位净收益、胜率、盈亏因子、最大回撤（逐笔累加、不复利）、平均净收益的 95% 自助法区间、出场原因分布、资金费为假设值的笔数。

## 6. 跑真实数据还缺什么
