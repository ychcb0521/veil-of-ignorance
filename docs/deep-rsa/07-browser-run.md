## 程序做了什么（`src/lib/deepRsa/pipeline.ts`）

| 阶段 | 内容 |
|---|---|
| 整理事件 | 排除组之外、有锚点的战役按同标的 48h 单链去重成簇；簇标签：含正不含对照 → 正，含对照不含正 → 对照，一正一负或含冲突组 → 不进标签目标；另抽随机背景时点（≤ 150 个，不预设为失败） |
| 拉取 K 线 | 每个事件取 [t₀ − 48h, t₀ 后第一根整点 + 24h) 的 5m K 线，含主动买入量；并发 4；限流按 Retry-After 退避 |
| 计算特征 | 观察窗覆盖率 ≥ 95% 才算；h = 2 / 6 / 12 各一套 15 个特征；结果期覆盖率 ≥ 95% 才有「24h 最大涨幅」 |
| RSA 训练集 | 按时间 60/20/20 切分（隔离带 72h）；3 类表征 × 3 个 h × 2 个目标 = 18 个 Mantel 检验（1999 次置换，按月分块），整面板 Holm |
| 测试集检验 | 每个 表征 × 目标 在验证集上选 h 并冻结；训练集在该 h 上 Holm p < 0.05 且 ρ > 0 的才上测试集，测试集只读一次，再做 Holm |
| 扫描与回测 | 只有「正 / 对照标签」目标样本外通过才做：训练集拟合中心模型，验证集 80% 分位定阈值，测试期逐 5m 扫描（同标的冷却 24h），与「48h 动量」「定期买入」同条件比较；24h 到期出场，手续费每边 0.05%，滑点 0 / 5 / 10 个基点，真实资金费（拿不到按 0.01%/8h 并计数） |

## 用户确认的口径（2026-10-15）

- 谢林三个候选（12h 滚动 VWAP、成交密集区 POC、手填兜底价）并列算。战役没有兜底价，候选 c 在战役样本里全为空，会被标准化弃用。
- 订单流用 5m K 线自带的主动买入量做代理。
- 对照组保留现有规则（盈亏比 < 0.5 即对照，亏损单全在其中），同时加跑「24h 最大涨幅」目标：ln(24h 内最高价 / t₀ 后第一根开盘价)，与操作无关，背景时点也参与。

## 结论怎么标

| 结论 | 已验证 | 检验未获支持 | 待验证 |
|---|---|---|---|
| 表征与目标同构 | 测试集 Holm p < 0.05 且 ρ > 0 | 训练集无项通过，或测试集未通过 | 尚未运行 |
| 模型扣成本后优于基线 | 5 个基点下模型平均净收益 95% 区间下限 > 0，且高于两条基线 | 回测未做或未达标 | 尚未运行 |

「第 3 步 · 特征对比」只是训练集上的描述（均值与标准化差），不是检验。
