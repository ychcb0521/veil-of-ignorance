# 上涨后滞涨转弱／猛烈回调未创新高 · v1

动态筛选 ② 排除门槛的独立可选否决。默认关闭，仅启用它的新方案保存参数及 `entry-stall-turn-v1` 版本；不重写旧模板，不更改已有急跌、回撤、状态 S 或箱体算法。

按已收盘 1 分钟行情依次检查三个不重叠区间：

1. 上涨段：首根开盘到末根收盘涨幅达到门槛。
2. 滞涨段：该段涨幅／分钟数，相对上涨段涨幅／分钟数，不超过所设比例。下跌时推进速度为负。
3. 转弱段：平均收盘价低于紧邻它之前的等长区间，且末分钟收盘严格低于该前区间的最低价。

此分支三项同时成立才触发。没有上涨背景、仍持续向上推进、仅横盘、仅影线触碰支撑，都不单独构成此分支的否决。

触发时冻结转弱前等长区间的最高收盘价。之后只有连续 N 个分钟收盘均高于前一收盘，且最后收盘收复该冻结价，才解除锁定；N 与转弱确认分钟数相同。窗口滑动、重筛与暂停续跑不解除锁定。恢复后仍需满足其余必要条件及准入条件。

第二分支“猛烈回调未创新高”：在独立历史回看范围内，以已收盘分钟最高价的滚动最大值为前高；（前高－当前分钟收盘）／前高达到门槛时，冻结该前高并否决。触发后，即使回调收窄、连续反弹、重筛或前高滑出历史窗口，也须等待分钟收盘严格突破冻结前高才能解除。影线突破或收盘持平均不解除；不利用分钟内高低先后未知的低点计算回调。两种锁定独立，任一仍在则不入选。该分支可单独关闭，关闭时保留已输入门槛。

初值：独立历史回看 6 小时，上涨段 60 分钟且涨幅至少 1%，滞涨段 10 分钟且推进速度不超过前段 20%，转弱段 3 分钟；新启用此选项时同时开启猛烈回调分支，门槛 3%。仅为可调研究初值，未据用户截图反推最优参数，未验证收益。

首次判断需要“历史回看＋三段长度”的连续历史，用于因果重建回看范围内触发的锁定。历史不足等待；缺根或无效价格报错，不补造、不缩短窗口放行。每条记录使用独立的有限窗口，后续直接消费筛选已有分钟线；不逐分钟重复请求历史。

排除记录保存锁定状态、前段涨幅、相对推进速度、平均收盘变化及局部支撑读数；开启第二分支时还保存回调比例、锁定前高。原因保存触发时间与恢复价。v5 保留原实现，此新条件适用于 v6/v7 新方案。

# 持仓监测保护委托的盘面显示

从 Legs 已使用的 `qualityAdditionStopOrders` 读取加仓后 K、下移 K′ 和已保存的 F；复用亲自交易的 `buildCampaignReverseOrderPriceLines`。黄色虚线表示委托期间，实际触发的价格使用触发实线，撤单或换价保留原撤单标记。K 与 F 分别判断是否触发。

适配结果仅进入盘面与其管理控件，不写进真实委托、空单成交、风险计算或盈亏。镜像拆分同一买入批次不重复画；缺少已保存价位的旧记录不推算补造。现有 Legs、指标、PNG 盘面导出继续使用相同原始交易数据。
