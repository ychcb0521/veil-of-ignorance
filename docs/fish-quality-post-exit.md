# 鱼质量 · 卖出后反事实

每个卖出子算法的「持仓时间」后增加「卖后反事实」折叠组，默认折叠；展开后有10列，依次为0.5、1、2、4、6小时的峰值涨幅和静态最大回撤2。各方案独立展开/收起，支持数值排序，导出保留全部10项。

## 计算口径

- 起点为该方案实际最终卖出时间，基准为实际最终卖出价格。仍持仓或仅半仓镜像成交时不计算。
- 峰值涨幅 = max(0, 窗口最高价 / 卖出价 − 1) × 100%。
- 静态最大回撤2 = max(0, 1 − 窗口最低价 / 卖出价) × 100%。
- 五个窗口从同一卖出时点起累计，结束端不包含下一根分钟K线。只读取已收盘1分钟行情；保留完整精度，展示时才四舍五入。
- 完整窗口尚未过去时显示「待满」，不展示较短路径冒充完整读数；缺根或价格无效显示「缺数据」，不补零。
- 开盘成交可使用卖出所在分钟的后续行情。盘中止损/全仓限价止盈仅有分钟精度，无法分清该分钟高低点发生在成交前还是后，因此排除该分钟；从下一完整分钟观察至原窗口终点，提示中明确注明。非整分钟时间戳也仅使用卖出后完整分钟。

## 执行与隔离

展开时自动补算当前筛选范围内、已有最终卖出结果的记录；每分钟检查尚未完成的窗口。可独立暂停或重试，不改变勾选，也不重跑买入、卖出、镜像和加仓。

取数复用现有行情缓存与交易所限流。相同市场/交易所/标的/卖出时间/卖出价/分钟边界策略共享同一份反事实读数；身份版本为post-exit-v1。新增读数跟随账号保存，旧页面、后续缺数据或尚未完成窗口不能覆盖已成功保存的窗口。

反事实仅用于卖出后的研究展示与导出，独立于交易结果和公式快照。后续行情不得反馈给原卖出决策。
